Agents write more code than a human can reason about. The collaboration interface is a Lean spec, not the raw diff. Noether Gate searches for a violation and asks Lean to certify it. Accept the proof, deny the PR. Fail to prove a bug, stay green. That green is not correctness.

The gate

01 spec.md
Human-language bullets
preserves-sum, no-skip, refunds-bounded… the contract.
↓
02 search.py
Find a witness on a small grid
If nothing turns up, we cannot certify a bug.
↓
03 Scratch/Violation.lean
theorem : ¬ Property Impl
Corpus lemmas get cited here. They must not mention Impl.
↓
04 Lean kernel
lake env lean
The kernel either accepts the violation or rejects the certificate.
↓
05 verdict
deny or approve
Approve means we failed to prove a bug. Nothing more.

Why Corpus cannot mention Impl

Corpus/

Generic facts. Nat cancel, skip tables, list sums. They survive the deny-path patch because they never talk about the current model.

Safe.lean

Proofs that the good Impl satisfies the bullets. Not a default Lake target. A bad PR mutates Impl; these would break if they sat on the deny path.
